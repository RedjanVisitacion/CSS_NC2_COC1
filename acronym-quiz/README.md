# CSS Acronym Quiz ? Quiz 2

Run Start Oral Practice.bat, then use http://localhost:8766. Python is needed for this source version. The separate portable package includes its own runtime.

Students enter their name, get five minutes of study, and then answer all 30 acronyms in random order. Each prompt has a full shared word bank with all 30 meanings. Select a term to fill the answer box or type it, then press Submit answer. This is a matching quiz, not a four-option multiple-choice quiz. There are two minutes per question. Spelling is checked ignoring case, punctuation, and spacing; disc/disk variants are accepted.

Quiz 2 has its own records folder, saved study times, Excel scores, oral wheel, and browser recovery. Quiz 1 and its records stay separate. Restart password: Redjan09.

Prepared by Redjan Phil S. Visitacion. Terms follow the list supplied by the teacher.

All 30 supplied images are attached to the corresponding acronym question and study card. Captions clarify related examples for CMOS (battery), ATX (motherboard), and LED (front-panel indicators).
